# 발 아치 높이 시뮬레이터

내측 종아치 높이를 바꾸면 하중을 받을 때 아치가 얼마나 내려앉고, 족저압과 후족 정렬이 어떻게 달라지는지 실험하는 교육용 시뮬레이터입니다. 현재 버전은 **Ver0.0.5**입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 빌드나 설치는 필요 없습니다.

- 글꼴(IBM Plex)은 Google Fonts에서 불러옵니다. 인터넷이 없으면 시스템 기본 글꼴로 표시됩니다.
- `발 아치 높이 시뮬레이터.html`은 최초 원본이며 Ver0.0.1의 `index.html`과 내용이 같습니다(이후 버전은 `index.html`만 갱신).

## 기능

- **조건:** 아치 높이(14~52 mm), 아치 강성, 체중, 한 발에 걸리는 하중, 발 길이, 스팬(아치 길이), 인솔 아치 서포트, 발가락 젖힘
- **프리셋:** 높은 아치(요족), 정상, 낮은 아치(평발) / 양발 서기, 한 발 서기, 보행 입각기, 달리기 착지
- **화면:** 측면 뷰, 족저압 지도(오른발), 후면 뷰(후족 외번·내번)
- **수치:** 주상골 높이와 하강, 아치 인덱스, 아치각, 후족 정렬, 족저근막 장력, 접촉 면적, 최대 압력, 부위별 하중 분포
- **세 가지 아치 비교:** 같은 조건과 같은 색 스케일로 나란히 비교
- **아치 높이 스윕 그래프:** 그래프를 누르거나 끌면 아치 높이가 바뀝니다
- **보행 입각기 재생:** 하중과 발가락 젖힘이 보행 곡선대로 자동으로 변합니다
- **측정 데이터 불러오기:** 족저압 장비의 압력 격자 CSV를 불러와 시뮬레이션 결과와 비교합니다(센서 간격, 단위, 방향 설정 가능)
- **측정 방법 안내(`measure.html`):** 체중, 발 길이, 스팬, 앉은·선 자세 아치 높이, 아치 인덱스, 족저압 7단계를 단계별 그림과 쉬운 설명(초등학생 눈높이)으로 안내합니다
- **측정값 기록(`measure.html`):** 측정일, 이름·구분, 발(좌·우), 체중, 발 길이, 스팬, 아치 높이, 아치 인덱스, 메모를 저장하고 수정·삭제·CSV 저장을 할 수 있습니다. 주상골 하강은 자동 계산하며, 시뮬레이터가 지원하는 범위를 벗어난 값은 표시합니다
- **시뮬레이터에 적용:** 기록의 값을 URL(`index.html#h=..&len=..&span=..&mass=..`)로 시뮬레이터에 바로 넘깁니다. 기록은 브라우저(localStorage)에만 저장되어 다른 기기나 방문자에게는 보이지 않습니다

기본값(정상 발, 70 kg, 양발 서기)에서는 주상골 하강 7.0 mm, 아치 인덱스 0.24, 최대 압력 약 166 kPa가 나옵니다.

## 모델 가정

- 아치를 지붕형 트러스로 보고, 체중의 약 35%가 아치로 전달된다고 가정합니다. 아치 강성은 높이의 1.5제곱에 비례합니다.
- 주상골 하강 = 아치 부하 ÷ 아치 강성 (인솔과 윈들러스 효과는 하강을 줄이는 쪽으로 반영)
- 족저근막 장력은 트러스 타이 하중 = P × 스팬 ÷ (4 × 아치 높이)로 추정합니다.
- 후족 외번은 주상골 하강에 비례하는 단순 관계식을 쓰며, 높은 아치는 내번 쪽으로 이동합니다.

## 주의

교육용 단순화 모델입니다. 계수는 대표값에 맞춘 가정치이므로 개인 진단이나 제품 성능 예측에는 사용할 수 없습니다.
